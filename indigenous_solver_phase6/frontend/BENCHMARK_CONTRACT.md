# Phase 6.9 Benchmark Contract

## Endpoint

GET /benchmarks

The endpoint returns authoritative benchmark data generated by the C++ benchmark runner. The frontend must not synthesize timings, speedups, GPU counts, or certificates.

## Summary fields

status, modelCount, phase2TotalMs, phase3TotalMs, phase4TotalMs, aggregateSpeedup, phase3FasterCount, phase4FasterCount, certificatePassCount, gpuRuns, cpuRuns, timestamp, message.

## Case fields

model, phase2Ms, phase3Ms, phase4Ms, speedup, backend, status, certificatePassed, iterations, objective, message.

Null timing values mean that the corresponding phase was not measured. gpuRuns counts actual GPU executions reported by the runtime; it is not inferred from the requested backend policy.

If the endpoint is unavailable, the dashboard displays an explicit unavailable state.
